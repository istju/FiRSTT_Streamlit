# FiRSTT Streamlit Base v2

A FiRSTT projekt publikálható kiindulási rétege.

- `app.py` — Streamlit főoldal
- `data/maxwell_history.md` — Maxwell történeti háttér
- `data/equation_registry_v2.md` — Equation Registry v2
- `data/symbol_registry_v2.md` — Symbol Registry v2.0

Szándékosan nincs benne a teljes `quaternion_v2.py`, a nem publikált későbbi FiRSTT-elmélet vagy kész fizikai szimuláció. A szimulációs oldal csak fenntartott hely.

Futtatás:
```bash
pip install streamlit
streamlit run app.py
```
